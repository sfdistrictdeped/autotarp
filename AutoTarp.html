Printing instructions

  1. Choose your paper size and orientation, then set the poster rows and columns.
  2. Upload your image and check the full-poster and individual-sheet previews.
  3. Choose Print in Browser to open the system print dialog, or export the tiled PDF.
  4. In the print dialog, select the matching paper size and Actual Size / 100%. Disable “Fit to page” and browser headers/footers if available.
  5. For accurate alignment, print the calibration PDF first and measure its 100 mm reference line with a ruler.
Note: browser and printer-driver settings can affect margins and scaling. Verify a test sheet before printing the full poster.

For accurate output, print the PDF at Actual size / 100% and disable “Fit to page” in the PDF viewer. Printer margins vary by device.

AutoTarp Changelog

Version 1.4 — Major Update

  • Improves the UI workflow with a full-screen workspace, expandable workflow sections, a top toolbar for Undo/Redo and help, a Proceed to Print menu, and a larger preview area.
  • Adds floating Poster Summary and image-clarity warning controls, removing redundant summary and warning boxes below the preview.
  • Keeps the selected image visible as a static thumbnail until Remove Image is clicked; removing it restores image selection and drag-and-drop.
  • Hides the clarity-warning button when no image is loaded and refines image-quality detection to reduce false alarms on high-resolution images.
  • Fixes portrait paper proportions in the full-poster preview and aligns individual-sheet preview with PDF/browser print geometry.
  • Corrects tiled print output so white overlap areas are available for gluing.
  • Sets the default overlap to 25.4 mm (1 inch) per adjoining edge and allows users to adjust it in print settings.
  • Includes print/PDF geometry bug fixes and quality-of-life improvements.

Version 1.3 — Major Update

  • Moves AutoTarp into its own GitHub repository as a standalone app, separate from SFD OneDirectory.

Version 1.2 — Minor Update

  • Fixes Individual Sheets preview proportions to follow the selected paper orientation and dimensions.
  • Improves sheet-label readability in dark mode.
  • Updates the service-worker cache version to help the app refresh cached files for offline use.

Poster assembly guide

Arrange the sheets left to right, then move top to bottom. Each sheet is numbered in reading order.

Use the crop marks as cutting guides. Match the artwork at each shared edge; use the configured overlap to align sheets before taping.

Printing instructions & keyboard shortcuts

Print workflow: Choose your photo, set paper size and orientation, set poster rows and columns, review both previews, then use Proceed to Print to export a tiled PDF or print from the browser. For reliable sizing, print at Actual Size / 100% and disable “Fit to page” when available.
