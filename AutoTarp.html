Printing instructions

  1. Choose your paper size and orientation, then set the poster rows and columns.
  2. Upload your image and check the full-poster and individual-sheet previews.
  3. Choose Print in Browser to open the system print dialog, or export the tiled PDF.
  4. In the print dialog, select the matching paper size and Actual Size / 100%. Disable “Fit to page” and browser headers/footers if available.
  5. For accurate alignment, print the calibration PDF first and measure its 100 mm reference line with a ruler.
Note: browser and printer-driver settings can affect margins and scaling. Verify a test sheet before printing the full poster.

For accurate output, print the PDF at Actual size / 100% and disable “Fit to page” in the PDF viewer. Printer margins vary by device.

AutoTarp Changelog

Version 1.2 — Preview and offline improvements

Fixes Individual Sheets preview proportions so they follow the selected paper orientation and dimensions. Improves sheet-label readability in dark mode. Updates the service-worker cache version to help the app refresh its cached files for offline use.

Version 1.1.0 — Interface and custom-size fixes

Improves dark-mode readability for Portrait/Landscape orientation controls and the custom paper-size panel. Fixes the Millimeters/Inches selector for custom paper dimensions. Moves the theme switch to the upper-right corner on the home and layout pages. Clarifies beta labels for versions 0.1.0 through 0.7.0.

Version 1.0.0 — Stable public web-app release

Introduces the GitHub Pages-ready web app and a consolidated set of smart poster tools: poster summary, local presets, assembly guide, image-quality warning, PDF page selection, test printing, fit-to-page, undo/redo, custom print margins, dark mode, keyboard shortcuts, and clearer error messages. Preserves core tiling, PDF export, calibration, paper presets, custom sizes, and existing credits.

Beta 0.7.0 — Browser-printing reliability

Improves browser printing with a dedicated print layout, page sizing based on the selected paper and orientation, image-readiness checks, and one poster tile per printed page. Restores the About and credit information.

Beta 0.6.0 — Expanded poster controls

Builds on the earlier prototype with additional print and layout controls, including refinements to scaling, overlap, margins, and crop-mark handling.

Beta 0.5.0 — PDF and calibration improvements

Refines tiled PDF output and adds or improves print calibration support to help users check scale before printing a complete poster.

Beta 0.4.0 — Preview and layout refinement

Improves the poster preview and tile layout workflow, making it easier to see how artwork is divided across sheets before export.

Beta 0.3.0 — Paper and grid options

Expands paper-size and orientation handling and refines row-and-column controls for multi-page poster layouts.

Beta 0.2.0 — Image tiling prototype

Develops the initial image-to-poster workflow with configurable tile grids and early print/export functionality.

Beta 0.1.0 — Initial prototype

First working concept of AutoTarp: upload an image and split it across ordinary paper sheets to create a larger assembled poster.

Version notes summarize the project’s development milestones. Printing results may vary by browser, printer driver, and printer settings; test a page before printing a full poster.

Poster assembly guide

Arrange the sheets left to right, then move top to bottom. Each sheet is numbered in reading order.

Use the crop marks as cutting guides. Match the artwork at each shared edge; use the configured overlap to align sheets before taping.
